# Проверки Scout

## Сквозной прогон в Docker, 25 ноября 2026

В Chromium создан аккаунт, URL введён в поле «Ссылка на страницу». Раннер открыл
временную страницу с путём `/check/?path=/` и записал одну ошибку JavaScript.
При повторе Scout использовал тот же проект. Исправная страница завершилась со
статусом «Без находок». Из отчётов скачаны сгенерированные Playwright-тесты.
Проверка выполнялась в режиме одной страницы, на локальном тестовом сервере.

## Автоматические проверки, 15 ноября 2026

| Проверка | Результат |
| --- | --- |
| Gateway, включая раздачу фронтенда и закрытые API | 25 passed |
| Runner, включая уведомления и изоляцию ошибок доставки | 66 passed |
| Ruff check и format | Успешно |

В Chromium проверены вход, создание проекта и сценария, запуск прогона, отчёт,
отмена, выход и раскладка шириной 390 px. HTML в названии проекта отображается
как текст. Для этого UI-прогона gateway использовал тестовые gRPC-клиенты и FakeRedis;
полная цепочка с PostgreSQL и RabbitMQ не запускалась: Docker daemon недоступен.
Скриншоты локально: `artifacts/dashboard-desktop.png`, `artifacts/dashboard-mobile.png`.

## Независимая внешняя площадка

Площадка: [The Internet / Sauce Labs](https://github.com/saucelabs/the-internet),
приложение для автоматизированных acceptance-тестов.
Проверка выполнена в 07:24 UTC настоящим `SiteBrowser` без LLM и без разрешения
внутренних адресов:

| Страница | Фактическая находка | Ожидание выполнено |
| --- | --- | --- |
| `/javascript_error` | TypeError: Cannot read properties of undefined (reading 'xyz') | Да |
| `/status_codes/404` | HTTP 404 для document | Да |

Машинный отчёт: `artifacts/external/report.json`. Для обеих страниц созданы
Playwright-тесты. Попытка отдельно исполнить сгенерированный тест остановилась
на таймауте загрузки страницы (30 секунд); успешное повторное воспроизведение
сгенерированными тестами не подтверждено. Результат детектора не является
измерением способности LLM искать логические ошибки.

Повторить независимую проверку можно через ручной GitHub Actions workflow
`External browser smoke`. Для ручного запуска из `services/runner` используйте
`uv run python -m app.external_smoke`. CI прикладывает JSON и тесты к запуску workflow.

## Telegram

Проверены отключение при неполной настройке, структура запроса sendMessage,
обработка отказа API и сетевых ошибок, отсутствие токена в логах и сохранение
успешного результата прогона при недоступном Telegram. Реальная доставка в чат
не проверялась: для неё нужно настроить токен бота и ID чата оператора.
