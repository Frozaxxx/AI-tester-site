## Независимая внешняя площадка

Площадка: [The Internet / Sauce Labs](https://github.com/saucelabs/the-internet),
приложение для автоматизированных acceptance-тестов.
Проверка выполнена в 07:24 UTC настоящим `SiteBrowser` без LLM и без разрешения
внутренних адресов:

| Страница | Фактическая находка | Ожидание выполнено |
| --- | --- | --- |
| `/javascript_error` | TypeError: Cannot read properties of undefined (reading 'xyz') | Да |
| `/status_codes/404` | HTTP 404 для document | Да |

Машинный отчёт: `artifacts/external/report.json`. Для обеих страниц созданы
Playwright-тесты. Попытка отдельно исполнить сгенерированный тест остановилась
на таймауте загрузки страницы (30 секунд); успешное повторное воспроизведение
сгенерированными тестами не подтверждено. Результат детектора не является
измерением способности LLM искать логические ошибки.

Повторить независимую проверку можно через ручной GitHub Actions workflow
`External browser smoke` или командой из README. Рабочие артефакты игнорируются Git;
в CI JSON и тесты прикладываются к запуску workflow.
